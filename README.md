# AI-Enhanced Intrusion Detection System (IDS)

## Overview
This dissertation project compares traditional Intrusion Detection Systems (IDS) with AI-based IDS models using CICIDS2017 and UNSW-NB15 datasets.

## Objectives
- Compare SNORT with AI models
- Reduce False Positive Rate (FPR)
- Improve explainability using SHAP and LIME

## Models
- SNORT
- Feed Forward Neural Network (FFNN)
- Convolutional Neural Network (CNN)
- Long Short-Term Memory (LSTM)

## Datasets
- CICIDS2017
- UNSW-NB15

## Evaluation Metrics
- Precision
- Recall
- F1 Score
- F2 Score
- False Positive Rate (FPR)
- AUC-ROC

## Explainability
- SHAP
- LIME
